# Sistema Empresarial — downloads

Sistema para lojas no Windows: vendas com leitor de código de barras, cupom na
impressora térmica, estoque com fotos, caixa e relatórios. Funciona sem internet
no dia a dia.

Conheça o sistema: **https://meusistemaempresarial.vercel.app**

## Como instalar

1. Extraia o arquivo `SistemaEmpresarial.zip` em `C:\` (fica `C:\SistemaEmpresarial`).
2. Abra **Sistema Empresarial.exe**. Se o Windows mostrar "O Windows protegeu o
   computador", clique em **Mais informações** e depois em **Executar assim mesmo**.
3. Escolha **Testar grátis por 24 horas** ou **Comprar agora**.

Requisitos: Windows 10 ou 11. Impressora térmica de 58 ou 80 mm (opcional): o
instalador da impressora vem dentro do pacote, na pasta *Driver da Impressora*.

Quem já usa o sistema não precisa baixar de novo: ele avisa sozinho quando há
versão nova e se atualiza com um clique.
